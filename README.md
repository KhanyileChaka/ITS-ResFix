## Project Overview

ITS ResFix is a maintenance reporting and tracking platform for student accommodation. It connects Students, Managers, and Internal Maintenance Workers through a Flutter mobile app, an ASP.NET Manager web app, an ASP.NET Internal Worker web app, and a shared Supabase backend. Complaints are auto-assigned based on category rules, with a 48-hour response timer and email communication to a single external company.
